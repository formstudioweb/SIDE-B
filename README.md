# SIDE B — вініловий бар

Портфолійний сайт listening bar і магазину платівок.

## Запуск

```bash
npm install
npm run dev
```

Відкрити адресу, яку покаже термінал. Production-збірка: `npm run build`.

## Що працює

- адаптивна навігація;
- бронювання столу з підтвердженням;
- резерв квитків на події;
- додавання платівок у кошик;
- подарунковий сертифікат;
- favicon та метадані сторінки.
